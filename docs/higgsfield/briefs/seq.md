# family: seq

Three frames played under the "reading it… / setting the disposition… / choosing what they can say…"
steps while `/api/create` is running. The empty cartouche fills in as the sheet is written, and when
the response lands the real `type-*` plate swaps in.

The plate being cut while the API is being built. It is a thirty-second wait doing something.

Each frame is an **edit of the previous one**, so the oval and the guide-lines never move. Frame 1
is `type-none`, already generated — start from it.

## _defaults

`1:1` · `1024` · `refs: styleboard, paper, anchor`

## _framing

```
FRAMING: square 1:1, an oval portrait cartouche centred and filling most of the
frame, drawn as a plain engraved oval rule with a narrow hatched border.
```

## seq-create-1

`tier 4` · `1:1` · `1024` · `→ public/art/seq-create-1.webp` · `refs: type-none`

Edit of `type-none`.

```
Keep this exact oval, border and paper. Inside the empty oval, add only the first
construction marks of a portrait: a faint vertical centre line, one horizontal
eye line, and a light oval for the mass of a head. Pencil-weight, barely there,
the way a plate is set out before any ink is cut. No face, no features, no
hatching, no ink. Nothing but guide lines.
```

## seq-create-2

`tier 4` · `1:1` · `1024` · `→ public/art/seq-create-2.webp` · `refs: seq-create-1`

Edit of `seq-create-1`.

```
Keep this exact oval, border, paper and guide lines. Add a bare contour drawing
over the guides: the outline of a head, shoulders and hood in single clean
unshaded ink lines, with the placement of the eyes, nose and mouth indicated by
the lightest possible marks. No hatching anywhere, no tone, no modelling, no
detail. An outline only, and it must not resolve into a recognisable individual.
```

## seq-create-3

`tier 4` · `1:1` · `1024` · `→ public/art/seq-create-3.webp` · `refs: seq-create-2`

Edit of `seq-create-2`.

```
Keep this exact oval, border, paper and outline. Begin the hatching: lay
crosshatch into the hood and the shoulders and the shadow side of the head, so
those areas are fully modelled in the finished style. Leave the face itself
almost entirely un-hatched — bare paper with only the contour lines on it, as if
the engraver has done everything except the features. The person must still be
unreadable. This frame is a plate stopped one step short of a face.
```

The un-hatched face is the whole frame, and the model will keep wanting to finish it. Reject any
version with a resolved face — the point is that the character does not exist yet.
